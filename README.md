# FluxOrigami 🌌

**Design at the Speed of Thought.** 

FluxOrigami is an AI-powered Generative UI workspace that transforms natural language prompts into production-ready Tailwind CSS and HTML components. Built for modern product designers and frontend developers, it features a sleek glassmorphism interface, a live rendering sandbox, and a complete component management system.

## ✨ Features

* **AI Command Hub:** Describe your desired UI component in everyday English, and FluxOrigami’s AI engine (powered by Google Gemini) instantly folds it into clean, semantic code.
* **Live Interactive Sandbox:** Instantly preview generated UI components within an isolated iframe environment. Test layouts, responsiveness, and hover states without leaving the browser.
* **Code Inspector:** View the raw HTML and Tailwind CSS with a built-in one-click copy function to seamlessly export code into your own projects.
* **Iteration History:** Automatically tracks your generation history, allowing you to branch out, review past prompts, and restore previous iterations with a single click.
* **Component Library:** A built-in file explorer to save, organize, and categorize your favorite UI components into custom folders for a reusable design system.

## 🛠️ Tech Stack

* **Backend:** Python, Django, Django REST Framework
* **Frontend:** HTML5, Tailwind CSS (via CDN), Vanilla JavaScript
* **AI Integration:** Google Gemini API (`google-generativeai`)
* **Database:** SQLite
